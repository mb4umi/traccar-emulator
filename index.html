Traccar Emulator

Current speed beschleunigt die GPX-Wiedergabe. Gesendet wird nur alle Interval-Sekunden; Zwischenpunkte werden übersprungen. Leer: ursprüngliche GPX-Zeitabstände. „Jetzt“ sendet Live-Zeit, „GPX-Zeit“ beginnt am ursprünglichen Datum.

Keine GPX geladen

GPX laden, dann auf die Karte klicken, um den Startpunkt zu wählen.

Noise

Jede Übertragung erhält einen unabhängigen Offset innerhalb dieses Radius. 0 deaktiviert Noise. Die GPX-Strecke und Wiedergabezeiten bleiben unverändert; accuracy wird separat eingestellt.

Traccar-App-Einstellungen aus der URL

Diese Werte konfigurieren die Traccar-App. Der Emulator nutzt Current speed oder den festen Sendeabstand; er puffert keine Fehler und filtert keine Stillstände.

Messwerte

Geschwindigkeit wird in Knoten übertragen. Distance ist die berechnete Strecke ab GPX-Start und wird von Raceradar nicht gespeichert.

Weitere OSMAND-Parameter

Raceradar verwendet lat, lon, timestamp, accuracy, speed, batt, valid und alarm=sos. Weitere Werte werden mitgesendet, aktuell aber nicht gespeichert. location ist die Alternative zu lat/lon; deviceid ist die Alternative zu id in Traccar. Der Emulator nutzt lat/lon und die ID aus deiner URL.

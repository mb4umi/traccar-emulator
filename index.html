Traccar app settings from URL

These values configure the Traccar app. The emulator uses its own playback controls and send interval; it does not buffer failed requests or filter stationary points.

Measurements

Speed is sent in knots. Distance is calculated from the original GPX start and is not stored by Raceradar.

Additional OSMAND parameters

Raceradar uses lat, lon, timestamp, accuracy, speed, batt, valid and alarm=sos. Other values are sent but currently not stored. Traccar supports location instead of lat/lon and deviceid instead of id. This emulator uses lat/lon and the ID from your URL.
